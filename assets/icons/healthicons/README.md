# Health Icons

Estos 27 SVG proceden del conjunto abierto [Health Icons](https://healthicons.org/),
proyecto de Resolve to Save Lives. Se incluyen localmente para que Censo funcione
sin depender de una CDN y para que la impresión pueda esperar su carga.

La selección visual fue confirmada explícitamente para la versión 2.67. Los hashes
de los recursos elegidos se validan en `tests/health-icons-smoke.mjs`; no deben
reemplazarse por iconos «equivalentes» sin una nueva selección visual.
